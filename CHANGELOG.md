# Список изменений

## 0.1.0
- Первый выпуск. Автор — **Rimmer**. Плагин для CS2 / CounterStrikeSharp 1.0.377, вдохновлён BlockingZones 1.3 (CS:GO, Drumanid).
- Своя зелёная панорама **bz** (меню, полоса предпросмотра, баннер «Часть карты закрыта»), управление только цифрами
  1–9, 0 через PMM ≥ 1.3.00 (`NumberKeyPressed`); без мыши и чат-команд. `tools/gen_layout.py`, `build-addon.cmd`.
- Квота на каждый предмет, учитываются только живые игроки T+CT, в разминке предметы не спавнятся.
- Предпросмотр установки: призрак за прицелом, ориентация по нормали; 1 поставить, 2/3/4 поворот X/Y/Z, 5 сброс, 0 отмена.
- JSON по картам (`maps/<map>.json`, `maps/workshop/<id>/<map>.json`), `items.jsonc`, `config.jsonc`
  (JSON с комментариями, меню меняет только значения), `css_bz_reload`.
- Уведомления: чат и/или баннер bz (`MessageMode`, `NoticeSeconds`): плавное появление и угасание, полоска-таймер.
- Меню и полоса предпросмотра уменьшены до размера панели PMM / SimpleAdmin (x0.75).
- Отличия от BlockingZones 1.3: «Сохранить» не теряет предметы, скрытые квотой; предмет, поставленный админом,
  появляется сразу. Новое: «Показать все предметы», удаление выбранного предмета из настроек,
  «Передвинуть» поставленный предмет (вперёд/назад/влево/вправо от взгляда, вверх/вниз, возврат на место);
  шаги «Передвинуть» и «Поворот» переключаются клавишей 7 и настраиваются в конфиге (`MoveSteps`, `RotateSteps`).
- Исправлено: в английском меню вместо «Back» было «Сзади» — клиент переводил одиночное слово как
  токен своей локализации (позывной карты). К значениям из одного латинского слова добавляется неразрывный пробел.
